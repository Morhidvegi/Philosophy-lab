PHILOSOPHY LAB — DEEP EDITION

This is an installable Progressive Web App.

PHONE: host this folder on any HTTPS static host, open index.html through that site in Android Chrome, then use Install/Add to Home screen. The service worker then makes the library available offline after its first load.

The project includes the expanded philosophy library, active recall flashcards, notes, mastery tracking, quizzes, timeline, concepts, and course.
